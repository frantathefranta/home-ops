** Running a pod with multus networking and a nodeSelector
#+begin_src yaml
---
apiVersion: v1
kind: Pod
metadata:
  name: test-pod-1
  namespace: default
  annotations:
    k8s.v1.cni.cncf.io/networks: |
      [{
        "name":"multus-wireless",
        "namespace": "network",
        "ips": ["10.0.20.211/24"],
        "mac": "10:62:e5:18:1a:30"
      }]
spec:
  nodeSelector:
    kubernetes.io/hostname: talos-g3-mini
  tolerations:
    - key: special
      operator: Exists
      effect: NoSchedule
  containers:
  - name: ubuntu
    image: ubuntu:24.10
    command: ['sh', '-c', 'sleep 999']
    securityContext:
       privileged: true
#+end_src

** Fixing a deleted kube-dns service

#+begin_src yaml
apiVersion: v1
kind: Service
metadata:
  name: kube-dns
  namespace: kube-system
spec:
  clusterIP: 10.96.0.10
  clusterIPs:
  - 10.96.0.10
  - ${CLUSTER_SVC_IPV6_PREFIX}0:a
  internalTrafficPolicy: Cluster
  selector:
    k8s-app: kube-dns
    app.kubernetes.io/instance: coredns
    app.kubernetes.io/name: coredns
  ipFamilies:
  - IPv4
  - IPv6
  ipFamilyPolicy: PreferDualStack
  ports:
  - name: udp-53
    port: 53
    protocol: UDP
    targetPort: 53
  - name: tcp-53
    port: 53
    protocol: TCP
    targetPort: 53
  type: ClusterIP
#+end_src

* Applications
** TREK

TREK is reconciled from =kubernetes/apps/default/trek= and is available at
https://trek.franta.us through the internal Gateway. It uses its built-in
authentication; no OIDC provider or external API keys are required.

On first boot, TREK creates =admin@trek.local= with a random password printed
to the application log:

#+begin_src sh
kubectl -n default logs deployment/trek
#+end_src

Sign in and change the initial credentials before inviting other users.

The 10Gi =trek= Ceph PVC holds both =/app/data= and =/app/uploads= in separate
subdirectories. Kopiur snapshots and backs up the entire claim, including the
SQLite database, uploads, =data/.jwt_secret=, and =data/.encryption_key=.
Keep the encryption key with the database when restoring; losing it makes
stored credentials unreadable. The single-replica deployment uses =Recreate=
to avoid overlapping SQLite writers during upgrades.

The image entrypoint starts as root to fix volume ownership, then drops to
the =node= user (UID/GID 1000). Only =CHOWN=, =SETUID=, and =SETGID= are retained
for that startup step; the root filesystem is read-only with a writable =/tmp=.

Upstream: https://github.com/liketrek/TREK
