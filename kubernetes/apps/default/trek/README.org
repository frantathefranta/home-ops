#+title: TREK
* Initial login
On first boot, TREK creates =admin@trek.local= with a random password printed
to the application log:

#+begin_src sh :noeval
kubectl -n default logs deployment/trek
#+end_src

Sign in and change the initial credentials before inviting other users.

* Restoring credentials
TREK generates =/app/data/.encryption_key= for stored credentials and
=/app/data/.jwt_secret= for sessions. Preserve these files when restoring the
database; losing the encryption key makes stored credentials unreadable.
